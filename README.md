# Editor de Orçamentos TECAMA

Aplicativo Streamlit para editar o cabeçalho e os valores de um orçamento PDF exportado do Pontta sem converter o documento para Word.

## Rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar

Suba `app.py` e `requirements.txt` para um repositório GitHub e publique pelo Streamlit Community Cloud.
